# Draft 0.11.1 — refreshed glass icon

This patch updates Draft's macOS app icon to the new transparent glass Draft mark. Notes,
the vault format and all app features are unchanged.

## Update

- New app icon is used consistently by the app bundle and release assets.
- Existing in-app update verification, rollback and backup protections remain unchanged.

## Install (unsigned by Apple, read this first)

This build is signed with a development identity and is **not notarized**. macOS may warn that it
can't check the app. Open Draft once and, if needed, use System Settings › Privacy & Security ›
Open Anyway.
