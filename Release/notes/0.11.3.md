# Draft 0.11.3 — iPhone capture in notes

This patch restores native image capture and document scanning in the editor.

## What's new

- Use Continuity Camera to take a photo, scan a document, or add a sketch from a nearby iPhone.
- Captured images and scanned PDFs are inserted as Draft attachment blocks and saved into the vault.
- Plain-text AutoFill remains available in the editor's context menu.
- No vault format or existing note content changes.

## Install

This build is signed with an Apple Development identity and is **not notarized**. macOS may warn that it
can't check the app. Open Draft once and, if needed, use System Settings › Privacy & Security › Open Anyway.
