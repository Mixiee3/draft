# Draft 0.11.5 — more reliable updates

- Update installs now request macOS authorization when Draft is in a protected location such as `/Applications`.
- If installation is cancelled or fails, Draft keeps or restores the previous version, reopens it, and explains the issue on the next launch.
- A verified update is checked again before install and can relaunch without macOS blocking the downloaded app.
- First-time downloads now include a drag-to-Applications DMG installer. Draft's local runtime is bundled; no separate dependency download is needed.
- No note content or vault format changes.
