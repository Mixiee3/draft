# Draft 0.11.2 — update notes polish

This patch improves the in-app update sheet.

## What's new

- Release notes now appear under a labelled **What's new** section.
- Empty release-note data no longer leaves behind a blank rounded rectangle.
- Update notes have explicit light/dark-mode contrast and remain readable when long.

The new glass app icon from 0.11.1 is unchanged.

## Install (unsigned by Apple, read this first)

This build is signed with a development identity and is **not notarized**. macOS may warn that it
can't check the app. Open Draft once and, if needed, use System Settings › Privacy & Security ›
Open Anyway.
