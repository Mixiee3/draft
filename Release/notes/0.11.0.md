# Draft 0.11.0 — first public release

Draft is a local-first notes app for macOS. Your notes are plain files you own. Nothing leaves your Mac unless you turn on a feature that needs the network.

## What's new
- Folders nest: New Subfolder in a folder's menu.
- Drag a note from the board or the sidebar onto a folder to move it.
- Focus Mode in the rail menu; Present from Info.
- Check for Updates, backup archives, Help and Privacy centers from earlier builds.

## Install (unsigned by Apple, read this first)
This build is signed with a development identity and is **not notarized**. macOS will warn that it can't check the app.
1. Open the downloaded app once and dismiss the warning.
2. Open System Settings › Privacy & Security, scroll down, and click **Open Anyway** next to Draft.
3. Enter your password. Later launches open normally.
