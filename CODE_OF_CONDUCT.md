# Code of Conduct

We want Draft's community to be welcoming and respectful to everyone, whatever their background,
experience, language or way of working.

## Expected behaviour

- Be kind and assume good faith.
- Critique code and ideas, not people.
- Respect privacy: never publish someone's notes, vault, or personal details without permission.
- Keep discussions on topic, and write in the language you're comfortable with (Czech, German and English are all welcome).

## Unacceptable behaviour

- Harassment, insults, threats, or discrimination of any kind.
- Publishing private information about others.
- Spam, or pressure to share secrets such as keys or tokens.

## Enforcement

Maintainers may remove comments, commits or issues that break these rules, and may restrict or ban
participants who repeatedly do so. To report a concern, open a private report through GitHub
(repository Security tab, or the maintainer's profile contact). Reports are read by maintainers and
handled confidentially.

This code is adapted from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
